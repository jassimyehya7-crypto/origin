## ✅ Points forts

### 🎨 Design & UI
- **Navigation moderne** : Tabs pill buttons (desktop) + Bottom nav (mobile) — pas de doublon
- **KPI cards** visuelles avec icônes colorées et hover effects
- **Cards de réservation** avec bordure latérale colorée (jaune = demande, vert = confirmée)
- **Sous-titres explicatifs** sous chaque section ("Le client attend votre réponse", "Le client va venir chercher sa commande")
- **Badges de statut** visuels avec couleurs distinctes
- **Avatar du commerce** avec initiale (header desktop + page Magasin)
- **Typographie cohérente** : font-display pour les titres, font-black pour les chiffres
- **Code couleur respecté** : ec-yellow, ec-green, ec-red, ec-blue, ec-ink

### ⚡ Fonctionnalités
- **Countdown live** sur les offres à durée limitée (mise à jour toutes les 30s)
- **Suppression optimiste** : l'offre disparaît instantanément de la liste
- **Actions optimistes** : les réservations disparaissent de la section en cours avant confirmation serveur
- **Toast notifications** après chaque action (Confirmée ✓, Refusée, Récupérée ✓)
- **Undo "Pas venu"** avec bouton Annuler pendant 30 secondes
- **Amélioration IA du texte** (bouton "Améliorer le texte" sur le titre)
- **Upload photo** avec prévisualisation centrée
- **5 types d'offres** avec descriptions claires et distinctes
- **Bouton retour** sur la page Nouvelle offre
- **Fuseau horaire** forcé Europe/Zurich (plus d'erreur d'hydratation)

### 📱 Mobile
- **Bottom nav** avec 3 onglets (Aujourd'hui, Offres, Magasin)
- **Header compact** (logo uniquement, pas de doublon avec la nav)
- **Boutons tactiles** : h-12 minimum, touch-manipulation, active:scale
- **Safe areas** respectées (env(safe-area-inset-bottom))
- **Backdrop blur** sur la bottom nav et le header sticky

### 🔒 Backend & Auth
- **Auth auto en mode dev** : bypass automatique quand Supabase n'est pas configuré
- **router.refresh()** isolé dans try/catch silencieux (plus d'erreur "signal error 1")
- **API endpoints** fonctionnels : PATCH réservations, DELETE offres, POST nouvelles offres
- **Middleware** auto-login sur toutes les routes API

## ⚠️ Points à améliorer

### 🔴 Priorité haute

| # | Problème | Page | Impact | Effort |
|---|----------|------|--------|--------|
| 1 | **Pas de modification d'offre existante** | Offres | Le commerçant ne peut pas éditer une offre publiée (prix, stock, titre) | Moyen |
| 2 | **Pages non redesignées** | Réservations, Clôture | Incohérence visuelle avec le nouveau design | Moyen |
| 3 | **Pas de pagination/recherche** | Offres | Si le commerçant a 50+ offres, la liste devient ingérable | Faible |
| 4 | **Pas de badge notification** | Navigation | Pas d'indicateur de nouvelles demandes sur l'onglet "Aujourd'hui" | Faible |

### 🟡 Priorité moyenne

| # | Problème | Page | Impact | Effort |
|---|----------|------|--------|--------|
| 5 | **Dashboard : pas de lien rapide "Créer une offre"** | Dashboard | Le commerçant doit naviguer vers Offres puis cliquer Ajouter | Faible |
| 6 | **Pas de graphique/tendance** | Dashboard | Pas de vision historique ( CA semaine, réservations/jour) | Élevé |
| 7 | **Magasin : infos en lecture seule** | Magasin | Adresse, téléphone non éditables par le commerçant | Moyen |

| 10 | **Header mobile : pas d'indicateur de page** | Mobile | On ne sait pas sur quelle page on est (juste le logo) | Faible |

### 🟢 Priorité basse (nice-to-have)

| # | Problème | Page | Impact | Effort |
|---|----------|------|--------|--------|
| 11 | **Pas de dark mode** | Toutes | Pas adapté pour une utilisation en soirée | Élevé |
| 12 | **Pas de haptic feedback** | Mobile | Pas de vibration lors des actions confirmées | Faible |
| 13 | **Pas de scan QR intégré** | Pro | Le scan QR est sur une page séparée (/pro/scan) | Moyen |

## 🔍 Détail par page

### 📋 Dashboard (`/pro`)

**Ce qui fonctionne bien :**
- 4 KPI cards en grille (2×2 mobile, 4×1 desktop)
- Greeting "Bonjour 👋" + heure de fermeture
- Sections "Nouvelles demandes" et "Confirmées · à préparer" avec sous-titres
- Actions optimistes avec rollback en cas d'erreur

**À améliorer :**
- Ajouter un bouton flottant "+" pour créer une offre rapidement
- Ajouter un mini-graphique de tendance (réservations des 7 derniers jours)
- Ajouter un lien "Voir l'historique" vers `/pro/reservations`
- Badge de notification sur l'onglet quand il y a des demandes en attente

### 🏷️ Offres (`/pro/offres`)

**Ce qui fonctionne bien :**
- Countdown live pour les offres à durée limitée
- Suppression optimiste (disparaît immédiatement)
- Photos centrées avec object-contain
- Badge de statut coloré par état
- Stats en sous-titre (total, publiées, brouillons)

**À améliorer :**
- Ajouter un bouton "Modifier" sur chaque offre
- Ajouter un filtre (toutes / publiées / brouillons / expirées)
- Ajouter une barre de recherche par titre
- Ajouter un tri (récent, prix, stock)
- Gérer l'édition d'une offre existante (page `/pro/offres/[id]/edit`)

### ➕ Nouvelle offre (`/pro/offres/nouvelle`)

**Ce qui fonctionne bien :**
- Bouton retour "← Retour aux offres"
- Photo centrée avec upload caméra/galerie
- Types d'offres avec descriptions explicites
- Limite flexible : quantité OU durée de validité
- Amélioration IA du texte

**À améliorer :**
- Ajouter un mode brouillon (sauvegarder sans publier)
- Ajouter un aperçu "Comment les clients verront l'offre"
- Ajouter la possibilité de planifier une offre (publication différée)

### 🏪 Magasin (`/pro/parametres`)

**Ce qui fonctionne bien :**
- Avatar du commerce avec initiale
- Cards structurées par section (Commerce, Horaires, Abonnement, Interface)
- Indicateur de statut abonnement avec point coloré
- Compteur de retraits du jour

**À améliorer :**
- Rendre l'adresse et le téléphone éditables
- Ajouter les jours d'ouverture (lundi-vendredi, etc.)
- Ajouter un champ "Description du commerce" éditable
- Ajouter un lien vers les statistiques détaillées
- Ajouter la gestion du logo/photo du commerce

## 📐 Architecture technique

### Stack
- **Framework :** Next.js 14.2.35 (App Router)
- **Styling :** Tailwind CSS 3.4 + design tokens personnalisés
- **Backend :** Supabase (production) / Store local en mémoire (dev)
- **Auth :** Cookies httpOnly + bypass dev mode
- **Icônes :** Lucide React

### Structure des fichiers
```
src/app/pro/
├── page.tsx              # Dashboard (Server Component)
├── layout.tsx            # Layout Pro (ProChrome)
├── offres/
│   ├── page.tsx          # Liste offres (Server Component)
│   ├── OffersList.tsx    # Liste offres (Client Component)
│   ├── OffersToast.tsx   # Toast de notification
│   ├── PublishButton.tsx # Bouton publier
│   ├── DeleteOfferButton.tsx # Bouton supprimer
│   └── nouvelle/
│       ├── page.tsx      # Page nouvelle offre
│       └── CreateOfferForm.tsx # Formulaire
├── parametres/
│   └── page.tsx          # Page magasin
├── reservations/         # ⚠️ Non redesigné
└── cloture/              # ⚠️ Non redesigné

src/components/pro/
├── ProChrome.tsx         # Layout principal
├── ProSidebar.tsx        # Sidebar + TopTabs + MobileNav
├── TodayInbox.tsx        # Inbox réservations
├── PendingInbox.tsx      # Legacy inbox (partagé)
├── InterfaceModule.tsx   # Module tablette/téléphone
└── OpenUntilEditor.tsx   # Éditeur heure fermeture
```

## 🎯 Recommandations prioritaires

1. **Édition d'offre** — Ajouter la possibilité de modifier une offre existante (priorité #1 pour les commerçants)
2. **Redesign Réservations & Clôture** — Harmoniser avec le nouveau design
3. **Badge notification** — Indicateur visuel de nouvelles demandes dans la nav
4. **Lien rapide "Créer"** — Bouton flottant ou lien depuis le dashboard
5. **Infos magasin éditables** — Le commerçant doit pouvoir modifier ses infos
